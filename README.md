# Student Management System (Java OOP)

## About
This is a simple Java console project for managing students.  
It allows adding, viewing, updating, and deleting student records.

## Features
- Add student  
- View students  
- Update student  
- Delete student  

## OOP Concepts Used
- Encapsulation (Student class with private variables and getters/setters)
- Inheritance (if used in project)
- Polymorphism (if used in project)
- Abstraction (if used in project)

## How to Run
Compile:
javac src/*.java

Run:
java Main
