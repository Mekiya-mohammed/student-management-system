Student Management System (Java OOP)
About
This is a simple Java console-based Student Management System project created using Object-Oriented Programming concepts.
The program displays student information such as:
Student Name
Student ID
Department
Other basic student details
OOP Concepts Used
Encapsulation
Classes and Objects
Constructors
Methods
How to Run
Compile: javac src/*.java
Run: java Main
Note
This project was created for practicing Java OOP concepts
